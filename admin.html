Giúp website của bé Linh luôn hiển thị đúng 100% trên mọi điện thoại & máy tính.

⚡ Cách 1: Lưu tức thì trên trình duyệt máy này

Bấm nút "Lưu & Đồng Bộ Sang Index" ở thanh trên cùng. Trang index.html trên máy của bạn sẽ lập tức cập nhật dữ liệu mới mà không cần chạm vào code!

🌍 Cách 2: Lưu vĩnh viễn trên toàn thế giới (GitHub & Vercel)

Để khi bé Linh mở điện thoại của bé lên vẫn thấy ngay mốc thời gian này mà không cần đăng nhập:

  1. Bấm nút "Tải File love_data.json" bên dưới.
  2. Chép đè file này vào thư mục data/love_data.json của dự án.
  3. Mở Terminal chạy lệnh: 
    git add data/love_data.json && git commit -m "update: Cập nhật timeline kỷ niệm" && git push origin main
  4. Vercel sẽ tự động build lại trong 10 giây và áp dụng vĩnh viễn cho tất cả mọi người!
